## 3. Modifiche, con il diff previsto

### 3.1 Bordo di misura: contatore, CPU e timestamp in una sola chiamata

Oggi `read_cpu_edge` è un `classmethod` che legge albero, cpu_times e busy, ma
non il contatore e non registra alcun istante (`:1807-1820`). L'energia arriva
dopo, per interpolazione sul buffer (`_emi_cum_at`, `:1118-1139`), a un istante
che è quello di Python e non quello del record EMI (il sampler prende `t` prima
dell'IOCTL, `:1048` e `:1054`).

**Prima**

```python
@classmethod
def read_cpu_edge(cls) -> Dict[str, object]:
    tree = cls.find_worker_tree()
    worker = read_worker_cpu_times(tree)
    busy = cls._system_busy_seconds()
    return {"tree": tree, "worker": worker, "busy": busy}
```

**Dopo** (metodo di istanza: serve `self._emi`; l'unico chiamante è
`SESSION.read_cpu_edge()`, `benchmark_unified.py:780`, `:789`)

```python
def read_counter_edge(self) -> Dict[str, object]:
    """Una IOCTL, con il timestamp del record PKG."""
    t_wall = time.time()
    t_mono = time.monotonic()
    counter, err = None, ""
    try:
        if self._emi is None:
            err = "backend EMI non aperto"
        else:
            d = self._emi.read_domains()
            if d is None:
                err = "read_domains() -> None"
            else:
                counter = {
                    "pkg_j": d["pkg"][0],
                    "pkg_pwh": d["pkg"][2],
                    "ts_100ns": d["pkg"][1],
                    "pp1_j": d["pp1"][0],
                }
    except Exception as exc:
        err = f"{type(exc).__name__}: {exc}"
    return {"counter": counter, "counter_error": err,
            "t_wall": t_wall, "t_mono": t_mono}

def read_measurement_edge(self) -> Dict[str, object]:
    """Contatore, albero, cpu_times e busy nello stesso bordo.

    Ordine: contatore per primo (la finestra energetica e' la sua), poi le
    letture CPU. Lo scarto fra i due e' dichiarato in ``edge_spread_s``.
    """
    t_before = time.monotonic()
    cnt = self.read_counter_edge()
    t_cpu_before = time.monotonic()
    tree = self.find_worker_tree()
    worker = read_worker_cpu_times(tree)
    busy = self._system_busy_seconds()
    t_after = time.monotonic()
    return {
        "tree": tree, "worker": worker, "busy": busy,
        "counter": cnt["counter"], "counter_error": cnt["counter_error"],
        "t_wall": cnt["t_wall"], "t_counter_mono": cnt["t_mono"],
        "t_before": t_before, "t_cpu_mid": (t_cpu_before + t_after) / 2.0,
        "t_after": t_after, "edge_spread_s": t_after - t_before,
    }
```

`read_cpu_edge` resta come alias di compatibilità, restituisce le stesse
chiavi storiche più le nuove.

**Fallback dichiarato.** Se `counter` è `None`, il bordo porta
`counter_error` e l'energia torna al percorso di oggi (buffer o campioni), con
`emi_edge_source = "buffer-interp"` oppure `"samples-fallback"`. Il token è
nella riga: non esiste un bordo "sincrono" presunto.

### 3.2 `_system_busy_seconds`: una sola lettura

Oggi la funzione legge `psutil.cpu_times()` per l'idle (`:1750`) e poi
`psutil.cpu_times(percpu=True)` per il totale (`:1758`): numeratore e
denominatore del denominatore vengono da due istanti diversi. Correzione
minima, stesse unità e stesso significato (`busy = totale − idle`):

```python
@staticmethod
def _system_busy_seconds() -> float:
    per = psutil.cpu_times(percpu=True)
    total = sum(sum(v for v in c if isinstance(v, (int, float))) for c in per)
    idle = sum(getattr(c, "idle", 0.0) for c in per)
    return max(total - idle, 0.0)
```

### 3.4 `Δt_W` dalla coppia di bordi, `cpu_share_window_s` dal tratto CPU

Oggi `dt` è `t_end − t_start` sull'orologio di Python (`local_energy.py:206`)
e diventa sia `duration_s` (`:225`) sia `cpu_share_window_s` (`:430`), mentre
l'energia è interpolata a quegli istanti. Sono due intervalli diversi.

**Dopo**, in `profile_window`, parametri additivi (default = comportamento di
oggi, così i test esistenti restano validi):

```python
def profile_window(
    self, t_start, t_end, ollama_pids=None, direct_io_delta=None,
    direct_cpu_delta=None, direct_busy_delta=None,
    worker_exit_in_window=False, exclude_windows=None,
    edge_start=None, edge_end=None, baseline_pre_w=None,
    engine_tree_changed=False, tree_born="", tree_lost="",
):
```

Se entrambi i bordi ci sono:

```python
dt_w, edge_time_source = self._edge_dt_w(edge_start, edge_end)
dt_cpu = (edge_end["t_cpu_mid"] - edge_start["t_cpu_mid"])
res.dt_W_s = dt_w
res.duration_s = dt_w
res.cpu_share_window_s = dt_cpu
res.edge_time_source = edge_time_source   # emi-counter-ts | python-monotonic
res.edge_spread_s = max(edge_start["edge_spread_s"], edge_end["edge_spread_s"])
res.emi_ts_start_100ns = _ts(edge_start)
res.emi_ts_end_100ns = _ts(edge_end)
res.edge_start_utc = _iso(edge_start["t_wall"])
res.edge_end_utc = _iso(edge_end["t_wall"])
```

`_edge_dt_w` usa la differenza dei `ts_100ns` del PKG quando entrambi i bordi
hanno un contatore; altrimenti la differenza dei `t_mono`, con il token
`python-monotonic`. La baseline usa `dt_w`
(`res.baseline_energy_j = P_pre * dt_w`), non `dt`. `cpu_share_window_s` usa
il tratto in cui sono state lette le CPU, non la finestra energetica: la
disuguaglianza `d_busy ≤ core · cpu_share_window_s` torna verificabile.

Il residuo è dichiarato, non azzerato: `edge_spread_s` è il tempo di
enumerazione e IOCTL ai due bordi; `t_cpu_mid` è il centro del tratto CPU,
non un istante magico. Con il canale EMI la finestra energetica non dipende
più da quell'approssimazione.

**Decisione da approvare (D2).** Il segmento del LLM Judge è oggi sottratto
per interpolazione. Con i bordi diretti si legge una coppia di contatore anche
all'inizio e alla fine della chiamata al giudice (una IOCTL per bordo, dentro
`_judge_via_energy_session`); se una delle due letture manca, si torna
all'interpolazione con `judge_energy_edge_source = "buffer-interp"`. In
alternativa si tiene l'interpolazione per il solo giudice e la si dichiara:
costa meno, ma lascia un segmento non sincrono in una riga che dichiara il
contrario per il resto.

## 6. Decisioni che servono prima di implementare

* **D1** — `engine_tree_changed`: esclusione della riga (raccomandata) o `s`

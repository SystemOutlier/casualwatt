    CO1  mild accident -> Accident=Mild invece di ThisCarDam=Mild

Sulle tre query controfattuali il riferimento non e' unico finche' non si fissa

contiene Py: quel valore non dipende da come si stima Py.

Sulla CF3 va detto una cosa, perche' "between 0 and 0.0" si legge come "nessun
effetto" e non lo e'. P(Theft=True | do(SocioEcon=Wealthy)) vale 4.87e-05: il
limite superiore e' corretto ed e' piu' piccolo dell'ultimo decimale che cobound
stampa (round a 4 decimali). Ho lasciato il formato com'e', perche' e' il suo, e
lo dichiaro qui: su quella query quattro decimali non bastano.

expected_probability resta vuota su queste tre righe: un intervallo non e' una
probabilita' puntuale, e un confronto a tolleranza su quella colonna non avrebbe
senso. Se le serve un confronto automatico, va deciso anche come si confrontano
due intervalli.

Come si lanciano
---------------------------------------------------------------------

Dalla cartella in cui ha scompattato, con il python del suo ambiente:

    python verifica_copie.py
    python verifica_ground_truth.py
    python verifica_py.py
    python verifica_conterfactual.py --gruppo corretto
    python tabella_confronto.py --orig "C:\percorso\della\sua\cartella"
    python verifica_righe_dati.py --orig "C:\percorso\della\sua\cartella"

Le ultime due hanno bisogno anche dei suoi file originali, perche' eseguono la
stessa chiamata sui due lati: --orig indica la cartella che contiene agents.py,
tools.py e funtions.py. Scrivono un .md accanto a se'.

Un avviso per la lettura di tabella_confronto.md: il caso
"cau_inference(..., path=None)" sull'originale usa il percorso assoluto scritto
a riga 41 di tools.py, e quel percorso e' il suo. Sulla sua macchina quel caso
potra' quindi riuscire invece di fermarsi: e' il difetto stesso, il codice
funziona solo dove quel percorso esiste. Il caso della cartella di avvio
diversa invece dipende dal solo read_csv relativo e si riproduce ovunque.

ground_truth.csv si rigenera con

    python aggiungi_controfattuali.py

che riscrive lo stesso file.

La pipeline con un modello richiede Ollama e le librerie di agent_framework:

    set MUDILAB_ORIG=C:\percorso\della\sua\cartella
    python run_query.py "la domanda"

per usare le copie corrette invece degli originali basta mettere
set MUDILAB_COPIE=1 prima, e in quel caso i suoi originali non servono. run.cmd
fa lo stesso da cmd.exe; il modello si sceglie con MUDILAB_MODEL o come secondo
argomento:

    run.cmd "la domanda" llama3.2:3b

La variante (b) si lancia allo stesso modo:

    set MUDILAB_COPIE=1
    python run_orchestrato.py "la domanda"

Stampa lo stesso JSON di run_query.py con in piu' i token di ogni passo e, se il
modulo di misura del mio repository e' raggiungibile, i joule di ogni passo.
Su una macchina dove quel modulo non c'e' lo script gira lo stesso: nel campo
"misura" scrive che l'energia non e' disponibile e perche'.

Il confronto (a)/(b) fa le due varianti di sopra in un solo processo, quindi ha
bisogno del modulo di misura e di Ollama:

    set MUDILAB_COPIE=1
    python confronto_a_b.py --modello llama3.2:3b
    python confronto_a_b.py --modello llama3.1:8b

Scrive un JSON accanto a se' e stampa la tabella. Senza il modulo di misura non
parte (--senza-calibrazione toglie solo le tre finestre di baseline, non la
misura): i joule sono il punto del confronto.

La variante ibrida cambia solo il modello della spiegazione:

    set MUDILAB_COPIE=1
    set MUDILAB_MODEL_SPIEGAZIONE=llama3.2:1b
    python run_orchestrato.py "la domanda" --scarta-primo-run

--scarta-primo-run esegue una volta la pipeline senza usare quel risultato, cosi'
la misura cade sulla seconda esecuzione, quando i modelli sono in memoria e la
cache dei prompt e' calda; con MUDILAB_MODEL_SPIEGAZIONE uguale al modello
principale il comportamento e' quello di prima, senza secondo modello.

Su una macchina senza Graphviz pyagrum stampa all'import "Graphviz is not
installed": riguarda solo il disegno della rete, l'inferenza non lo usa, e
nell'output allegato non compare perche' l'avviso va sullo stderr.

Resto in attesa, poi procedo con la misura.
